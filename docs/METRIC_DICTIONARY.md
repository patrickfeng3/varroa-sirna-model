# Varroa vsiRNA Metric Dictionary

**Version:** 0.22  
**Scope:** Canonical metrics from Stage 01 through Stage 11 interactive region exploration  
**Rule:** Every important statistic must have a documented definition, analysis unit, direction, normalization, interpretation and limitation.

---

# 1. Metric classes

Each metric is labelled conceptually as one of:

```text
Standard/descriptive
Published-method-derived
Project-specific
Historical/regression
Canonical
Diagnostic
Sensitivity
```

A project-specific metric may be scientifically useful; the label prevents it being presented as a universally established RNAi statistic.

---

# 2. Analysis units

## `sample`

One sequencing library/sample.

Top-level cluster for canonical cross-dataset inference.

## `sample_virus_unit`

One virus analysed within one sample.

## `sample_virus_contig_unit`

One mapped viral contig within one sample-virus unit.

## `candidate`

One Stage 06 target interval of a specified length and coordinate.

## `target_candidate_length_stratum`

All candidates sharing:

```text
target_id × candidate_length_nt
```

Canonical unit for Stage 09 normalization, Stage 10A ranking, and selected-length Stage 11 region aggregation.

---

# 3. Weighting modes

## `abundance_weighted`

Observed sequence contribution is proportional to canonical read-level abundance.

Question:

> What dominates the accumulated sequenced population?

## `unique_sequence`

Each distinct sequence contributes total weight 1 within the stated analysis unit.

Question:

> Is a pattern represented broadly across distinct sequence species rather than being driven by highly abundant molecules?

Stage 01 unique identity:

```text
sample × analysis_unit × length × strand × sequence
```

Stage 05 positional unique identity:

```text
virus × strand × length × sequence
```

with total sequence weight distributed across compatible loci.

# 4. Stage 01 length-landscape metrics

## `length_count(L)`

Eligible viral small-RNA count/weight of length `L`.

Abundance mode:

```text
sum(read-level count)
```

Unique mode:

```text
number of distinct Stage 01 sequence identities
```

Canonical Stage 01 range:

```text
15–35 nt
```

## `length_fraction(L)`

```text
length_count(L)
/
Σ length_count(k), k=15..35
```

Range `[0,1]`.

Within-unit normalized length representation.

## `length_rank(L)`

Competition rank by descending `length_fraction`.

Tie pattern:

```text
1,2,2,4,...
```

## `top1_indicator(L)`

`1` when rank `<=1`, else `0`.

## `top3_indicator(L)`

`1` when rank `<=3`, else `0`.

These are descriptive.

## `count_23`

```text
count_23_sense + count_23_antisense
```

## `count_24`

```text
count_24_sense + count_24_antisense
```

## `antisense_fraction_23`

```text
count_23_antisense
/
(count_23_sense + count_23_antisense)
```

## `antisense_fraction_24`

Analogous for 24 nt.

Do not rename this `F24_AS`.

## `delta_antisense_fraction_24_minus_23`

```text
antisense_fraction_24
-
antisense_fraction_23
```

Positive = 24 nt more antisense-biased.

## `length23_fraction_among_23_24`

```text
count_23 / (count_23 + count_24)
```

## `length24_fraction_among_23_24`

```text
count_24 / (count_23 + count_24)
```

```text
pair-level metric
→ median across eligible viruses within each sample
→ median across samples
```

## `sample_clustered_CI95`

95% bootstrap interval from resampling biological samples while retaining observations from each selected sample together.

# 6. Stage 02 terminal coordinates

For physical RNA sequence:

```text
5′ N1 N2 ... N(n-1) Nn 3′
   ↑  ↑        ↑     ↑
 5p1 5p2      3p2   3p1
```

Observed antisense reads are already physical 5′→3′ sequences and are not reverse-complemented again.

Expected antisense sequence opportunity is generated by reverse-complementing reference windows.

# 7. Stage 02 terminal enrichment metrics

## `observed_terminal_weight(b,p)`

Observed eligible weight carrying base `b` at physical terminal position `p`.

## `observed_total_weight`

Total observed eligible weight in the same population.

## `observed_fraction(b,p)`

```text
observed_terminal_weight(b,p)
/
observed_total_weight
```

## `valid_background_window_count(L)`

Number of fully depth-supported A/C/G/T reference windows of length `L`.

Repeated identical strings at different genomic positions remain separate sequence opportunities.

## `expected_fraction_sense(b,p)`

Base frequency at position `p` among valid reference-orientation windows.

## `expected_fraction_antisense(b,p)`

Base frequency at position `p` after reverse-complementing each valid reference window.

## `observed_strand_weight_sense`

```text
sense_weight / (sense_weight + antisense_weight)
```

## `observed_strand_weight_antisense`

Analogous.

## `expected_fraction_combined(b,p)`

```text
wS × expected_fraction_sense
+
wAS × expected_fraction_antisense
```

## `enrichment_ratio(b,p)`

```text
observed_fraction / expected_fraction
```

Interpretation:

```text
1 = as expected
>1 = enriched
<1 = depleted
```

If expected frequency is zero, `NA`.

No pseudocount.

## `pair_median_enrichment_ratio`

Median finite pair-level enrichment across eligible sample-virus units.

Historical/regression summary.

## `sample_balanced_median_enrichment_ratio`

Median across viruses within sample, then median across samples.

Canonical cross-dataset summary.

## `pooled_abundance_enrichment_ratio`

Secondary molecular-pool descriptive enrichment where high-abundance units contribute proportionally.

Not the primary biological cross-sample estimator.

## `spearman_rho_23_24`

Spearman correlation between matched 23- and 24-nt terminal enrichment landscapes.

Measures similarity, not shared enzymatic origin.

# 8. Stage 03 stepRNA metrics

## `steprna_5p_distance`

Official signed 5′ distance relative to focal reference:

```text
negative = reference overhang
positive = reference underhang
0 = blunt
```

## `steprna_3p_distance`

Official signed 3′ distance with same convention.

## `steprna_log_ratio`

Official stepRNA enrichment/log-ratio statistic for a signed distance.

Published-method-derived.

## `steprna_wald_z`

Official stepRNA Wald Z statistic for one run/distance.

Do not reinterpret sample-aggregated medians as a new Wald test.

## `passenger_recovery_fraction`

Fraction of focal reference sequences for which at least one eligible opposite-strand passenger is recovered.

## `joint_duplex_count(d5,d3)`

Number of reconstructed same-duplex relationships having complete signed geometry `(d5,d3)`.

## `joint_duplex_fraction(d5,d3)`

```text
joint_duplex_count(d5,d3)
/
n_recovered_duplexes
```

for one run.

## `joint_00_duplex_fraction`

Special case:

```text
joint_duplex_fraction(0,0)
```

Fully blunt same-duplex prevalence.

## `varroa_2nt_joint_geometry`

Pre-specified special geometry:

```text
(+2,-2)
```

It is not assumed dominant.

## `varroa_2nt_joint_fraction`

Fraction of recovered duplexes supporting `( +2, -2 )`.

# 10. Stage 05 spatial/transitivity metrics

## `alignment_midpoint_nt`

Midpoint coordinate assigned to one compatible small-RNA alignment.

## `bin_index`

10-nt canonical genomic bin index.

## `anchor_bin`

High-signal bin selected using the pre-specified non-zero-bin percentile and minimum-separation rule.

## `D_24AS`

Normalized downstream-vs-upstream directional abundance effect for antisense 24-nt small RNAs under the exact canonical Stage 05 definition.

## `D_24S`

Equivalent effect for sense 24 nt.

## `delta_D_24AS_minus_24S`

```text
D_24AS - D_24S
```

Positive = stronger downstream directionality for antisense than sense.

No canonical result supported a positive effect after pre-specified multiple testing.

## `F24_AS`

Within a stated upstream/downstream window:

```text
24AS
/
(23AS + 24AS)
```

This is a composition fraction and is **not** `antisense_fraction_24`.

## `delta_F24_AS`

```text
F24_AS_downstream
-
F24_AS_upstream
```

Positive = downstream antisense 23+24 population is relatively more 24-nt-rich.

This is not the same as an absolute increase in 24AS abundance.

## `cross_correlation`

Lagged spatial association between pre-specified binned populations under the canonical Stage 05 definition.

## `permutation_p`

Monte Carlo permutation P-value using non-zero correction:

```text
(b+1)/(m+1)
```

where `b` is as/extreme null count and `m` valid permutations.

```text
target_sequence_dna with T→U
```

# 12. Stage 07 empirical sequence metrics

Stage 07 uses total viral small-RNA data and matched viral sequence opportunity.

It is not an AGO-specific or efficacy assay.

## `observed_base_fraction_unique(position,base)`

Fraction of distinct observed sequences carrying `base` at the guide position.

## `observed_base_fraction_abundance(position,base)`

Abundance-weighted observed fraction.

## `expected_base_fraction(position,base)`

Matched expected fraction among fully supported viral sequence opportunities.

## `representation_delta_unique`

```text
observed_unique_fraction - expected_fraction
```

## `representation_delta_abundance`

```text
observed_abundance_fraction - expected_fraction
```

## `accumulation_delta`

```text
observed_abundance_fraction
-
observed_unique_fraction
```

Positive = high-copy observed sequences are enriched for the feature relative to observed sequence diversity.

## `A10`

Binary guide feature:

```text
1 = guide position 10 is A
0 = otherwise
```

Literature-specified validation variable.

## `GC9_14_fraction`

GC fraction across guide positions 9–14.

Literature-specified continuous validation feature.

## `observed_GC9_14_mean_unique`

Mean `GC9_14_fraction` across distinct observed sequences.

## `observed_GC9_14_mean_abundance`

Abundance-weighted mean.

## `expected_GC9_14_mean`

Matched expected mean across valid sequence opportunities.

## `GC9_14_delta_unique_vs_expected`

```text
observed_GC9_14_mean_unique
-
expected_GC9_14_mean
```

## `GC9_14_delta_abundance_vs_expected`

```text
observed_GC9_14_mean_abundance
-
expected_GC9_14_mean
```

## `GC9_14_accumulation_delta`

```text
observed_GC9_14_mean_abundance
-
observed_GC9_14_mean_unique
```

## `regional_GC_fraction(start,end)`

GC fraction across one fixed six-nucleotide guide region.

Stage 07 scans every six-base region.

## `sign_test_raw_p`

Two-sided exact sign test on non-zero sample-level paired deltas.

## `bh_p`

Benjamini–Hochberg adjusted P-value.

Used for literature-specified validation family and sensitivity/comparability where specified.

## `by_p`

Benjamini–Yekutieli adjusted P-value.

Primary dependent-test correction for exploratory positional/regional discovery.

## `stage02_terminal_regression_status`

Mandatory QC showing Stage 07 terminal positions reproduce Stage 02.

## `A3p3`

Stage 07 named feature:

```text
1 = third nucleotide from physical guide 3′ end is A
0 = otherwise
```

## `GC_3p5_10`

GC fraction across guide positions 3p5 through 3p10 inclusive.

Six-base region.

Lower GC / higher AU was associated with greater empirical accumulation in Stage 07.

## `W7`

```text
1 = A/U at guide g7
0 = G/C
```

Not a default Stage 09 predictor.

## `R10`

```text
1 = A/G at guide g10
0 = C/U
```

## `W17`

```text
1 = A/U at guide g17
0 = G/C
```

Carry-forward Stage 09 predictors:

```text
A3p3
GC_3p5_10
W17
R10
```

plus the four terminal nucleotide categories.

# 14. Stage 09 common normalization

## `favourable_percentile`

Within:

```text
target × candidate_length
```

orient the metric so larger = more favourable.

Let:

```text
r_i = average ascending rank
n = number of candidates
```

Then:

```text
Q_i
=
(r_i - 0.5) / n
```

Range approximately `[0,1]`.

Ties use average rank.

If `n=1`:

```text
0.5
```

It is a target-relative empirical rank, not a biological probability.

**23 nt and 24 nt are never normalized together.**

# 15. Stage 09A training metrics

## `stage09a_training_opportunity`

One valid depth-supported theoretical antisense opportunity:

```text
sample × virus × length × exact antisense sequence
```

The theoretical antisense sequence is the reverse complement of the matched valid reference window.

Canonical empirical Layer-1 lengths in v0.20:

```text
23 nt
24 nt
```

Each length is modelled separately.

## `stage09a_represented`

```text
1 = exact antisense sequence observed
0 = valid opportunity exists but sequence unobserved
```

Used for accounting/QC and connection to Stage 07 representation evidence.

It is **not** the response of a new Stage 09A representation model.

## `stage09a_sequence_abundance`

Summed canonical read abundance for one represented:

```text
sample × virus × length × sequence
```

species.

Primary observed accumulation outcome.

## `stage09a_log_abundance`

```text
ln(stage09a_sequence_abundance)
```

for represented supported opportunities only.

No pseudocount.

Primary response for the length-specific weighted fixed-effect accumulation model.

# 17. Stage 09A model-definition metrics

## `layer1_fit_weight`

For one represented training observation in a single length-specific model:

```text
w_raw_i
=
1 / (G_s × N_g)
```

where:

```text
G_s
=
number of eligible sample-virus groups
contributed by biological sample s
for the current length and training set

N_g
=
number of represented training sequence species
in sample-virus group g
```

Rescale:

```text
w_i
=
w_raw_i
×
n_training
/
Σ_i w_raw_i
```

so mean training weight is 1.

Interpretation:

```text
equal total weight per biological sample
equal group weight within sample
equal species weight within group
```

Read abundance is the response and is not also used as a fitting weight.

## `layer1_group_fixed_effect`

Unpenalized nuisance intercept for one:

```text
sample × virus
```

group within one fixed candidate length.

Purpose:

```text
control baseline abundance differences among
viral/library groups
```

It is not transferred to target candidates.

## `layer1_model_family`

Canonical v0.20 value:

```text
weighted_fixed_effect_linear_regression
```

Response:

```text
ln(sequence abundance)
```

Penalty:

```text
none
```

Hyperparameter tuning:

```text
none
```

Model-structure search:

```text
none
```

Length handling:

```text
separate model for 23 nt
separate model for 24 nt
```

```text
β_hat_Lᵀ X_candidate
```

where `β_hat_L` is fitted from the final model for that same candidate length.

No viral nuisance group intercept is added.

Direction:

```text
higher
=
greater predicted Varroa viral-small-RNA

```

```text
predicted read count

```

Within:

favourable percentile of `layer1_accumulation_linear_predictor`.

# 19. Stage 09A validation metrics

## `layer1_lovo_group_spearman_rho`

Within one held-out:

```text
sample × virus × length
```

group:

```text
Spearman(
    sequence-only prediction,
    observed abundance
)
```

across all valid theoretical opportunities.

Unrepresented opportunities have observed abundance `0`.

Range:

```text
-1 to +1
```

Higher positive values indicate better ranking agreement.

## `layer1_lovo_group_top10_abundance_share`

For one held-out group:

```text
abundance in highest-scoring ceil(0.10 × n) opportunities
/
total observed abundance
```

If total observed abundance is zero:

```text
NA
```

## `layer1_lovo_group_top10_abundance_lift`

```text
layer1_lovo_group_top10_abundance_share
/
(ceil(0.10 × n) / n)
```

Interpretation:

```text
1   = random-level abundance capture
>1  = enrichment
<1  = depletion
```

## `layer1_virus_holdout_median_rho`

For one held-out virus/family and one length:

```text
median of valid sample-group Spearman rho values
```

## `layer1_virus_holdout_median_top10_lift`

For one held-out virus/family and one length:

```text
median of valid sample-group top10 abundance lifts
```

## `layer1_crossvirus_median_rho`

For one length:

```text
median of the virus-holdout median rho values
```

Reported separately for 23 nt and 24 nt.

## `layer1_crossvirus_positive_rho_count`

Number of held-out virus/family analyses with:

```text
virus_holdout_median_rho > 0
```

Reported as:

```text
count / number_of_valid_holdouts
```

## `layer1_crossvirus_median_top10_lift`

Median of virus-holdout median top10 lifts for one length.

## `layer1_crossvirus_top10_lift_gt1_count`

Number of valid virus/family holdouts with:

```text
virus_holdout_median_top10_lift > 1
```

## `layer1_coefficient_holdout_median`

For one fitted sequence coefficient and one length:

```text
median coefficient across the five
leave-one-virus/family-out fits
```

## `layer1_coefficient_holdout_min`

Minimum coefficient across the holdout fits.

## `layer1_coefficient_holdout_max`

Maximum coefficient across the holdout fits.

## `layer1_coefficient_same_sign_count`

Number of valid held-out-virus fits whose coefficient has the same sign as the final full-data coefficient.

Diagnostic only.

No coefficient-stability threshold is used as a candidate filter.

# 20. Stage 09B Layer-2 metrics

## `layer2_asymmetry_percentile`

Within-target, within-length favourable percentile of canonical `asymmetry_ddg_4bp`.

Higher / more positive = more favourable.

Metric class:

```text
Canonical
Project-specific normalization of published-method-derived biophysics
```

## `layer2_asymmetry_5bp_percentile`

Within-target, within-length favourable percentile of `asymmetry_ddg_5bp`.

Sensitivity only.

It contributes zero weight to `layer2_reference_score`.

## `layer2_self_fold_percentile`

Within-target, within-length favourable percentile of `guide_self_fold_mfe_kcal_mol`.

Higher / less negative = weaker predicted guide self-folding = more favourable.

## `layer2_reference_score`

```text
0.5 × layer2_asymmetry_percentile
+
0.5 × layer2_self_fold_percentile
```

Range `[0,1]`.

Neutral within-layer reference summary.

Not a learned biological weight and not an efficacy probability.

## `layer2_asymmetry_4bp_5bp_percentile_difference`

```text
layer2_asymmetry_percentile
-
layer2_asymmetry_5bp_percentile
```

Positive = candidate ranks more favourably under the canonical 4-bp definition.

Negative = candidate ranks more favourably under the 5-bp sensitivity definition.

Diagnostic only.

## `layer2_asymmetry_4bp_5bp_rho`

Within-target, within-length Spearman correlation between:

```text
asymmetry_ddg_4bp
asymmetry_ddg_5bp
```

Robustness diagnostic.

# 23. Stage 10A integration metrics

## `stage10_layer1_percentile`

Exact Stage 10 copy of:

```text
layer1_accumulation_percentile
```

within the same:

```text
target × candidate_length
```

stratum.

No second transformation is applied.

Higher = more favourable empirical accumulation propensity.

## `stage10_layer2_percentile`

Favourable percentile of:

```text
layer2_reference_score
```

within:

```text
target × candidate_length
```

Formula:

```text
(r_i - 0.5) / n
```

with average ascending ranks.

Purpose:

> place the Layer-2 composite on the same layer-level rank-percentile scale used for equal-layer Stage 10A integration.

Higher = more favourable.

This is a rank transform, not a probability.

## `stage10_layer3_percentile`

Favourable percentile of:

```text
layer3_reference_score
```

within:

```text
target × candidate_length
```

using the same formula and tie handling.

Higher = more favourable.

## `stage10_equal_layer_score`

Let:

```text
L1 = stage10_layer1_percentile
L2 = stage10_layer2_percentile
L3 = stage10_layer3_percentile
```

Then:

```text
stage10_equal_layer_score
=
(L1 + L2 + L3) / 3
```

Equivalent layer weights:

```text
L1 = 1/3
L2 = 1/3
L3 = 1/3
```

Metric class:

```text
Canonical
Project-specific
Neutral integration
```

Higher = more favourable.

Interpretation:

> average relative favourability across the three predefined evidence layers under an explicitly equal-layer integration rule.

Not:

```text
RNAi efficacy probability
knockdown percentage
mortality probability
AGO-loading probability
```

The equal thirds are not learned from Varroa efficacy data.

## `stage10_equal_layer_rank`

Average descending rank of `stage10_equal_layer_score` within:

```text
target × candidate_length
```

Direction:

```text
1 = best
lower = better
```

Equal scores receive average rank.

No coordinate- or ID-based tie break.

## `stage10_equal_layer_percentile`

Favourable percentile of `stage10_equal_layer_score` within:

```text
target × candidate_length
```

using:

```text
(r_i - 0.5) / n
```

with average ascending ranks.

Higher = better relative position.

## `stage10_pareto_dominates(A,B)`

Binary mathematical relation within one:

```text
target × candidate_length
```

stratum.

Candidate `A` dominates candidate `B` if:

```text
L1_A >= L1_B
L2_A >= L2_B
L3_A >= L3_B
```

and at least one inequality is strict.

Identical layer vectors do not dominate each other.

Dominance comparisons use full stored precision and are not performed on rounded display values.

This relation is an algorithmic definition; it need not be emitted as an all-pairs output table.

## `stage10_pareto_front`

Positive integer assigned by iterative non-dominated sorting.

Definition:

```text
front 1
=
candidates not dominated by any other candidate

front k
=
non-dominated candidates after fronts 1...(k-1)
have been removed
```

Direction:

```text
lower front number = stronger multi-objective position
```

Important limitation:

> Pareto front is not a complete ranking. Multiple candidates on the same front may represent different trade-offs.

It is complementary to `stage10_equal_layer_rank`.

## `stage10_minimum_layer_score`

```text
min(
    stage10_layer1_percentile,
    stage10_layer2_percentile,
    stage10_layer3_percentile
)
```

Range `[0,1]`.

Higher = stronger weakest evidence layer.

Diagnostic only.

It is not a gate, filter, tie-break, or primary ranking score.

## `stage10_layer_spearman_rho`

Within-target, within-length Spearman correlation between one pair of Stage 10 layer percentiles:

```text
L1 vs L2
L1 vs L3
L2 vs L3
```

Range `[-1,+1]`.

Diagnostic only.

## `stage10_pareto_front_n`

Number of candidates in one:

```text
target × candidate_length × pareto_front
```

group.

## `stage10_pareto_front_fraction`

```text
stage10_pareto_front_n
/
number of candidates in the target × candidate_length stratum
```

Diagnostic only.

# 25. Future user-configurable length status

The generic software architecture must allow:

```text
candidate_length = L
```

rather than hard-code only 23/24.

For a future user-selected length, each metric/model should have an evidence status such as:

```text
validated
generic_calculation
extrapolated
unsupported
```

For Varroa, 23/24 should currently be recommended but not enforced as the only allowed inputs.

The current Stage 09A empirical models are separately trained and validated for 23 nt and 24 nt. They must not be labelled validated for another length until that requested length has suitable training/validation evidence.

Stage 10A may integrate another candidate length only if the required Stage 09 layer values exist and their evidence status is exposed.

If multiple lengths are requested, each length remains a separate normalization/ranking population unless a future specification explicitly validates cross-length pooling.

```text

```

1-based inclusive.

A region is valid only when:

```text

```

## `stage11_region_n_contained_windows`

Number of selected-length Stage 10A candidate windows fully contained in one valid longer region.

For the exhaustive canonical candidate universe:

```text
R - L + 1
```

where:

```text

L = stage11_guide_length_nt
```

This is a QC invariant.

## `stage11_region_mean_score`

Primary Stage 11 region statistic.

For selected Stage 10A metric `M`:

```text
mean(
    M_i
    for every selected-L candidate i
    satisfying:

    candidate_start >= region_start
    candidate_end   <= region_end
)
```

Higher = more favourable.

No weighting among contained candidate windows.

No additional smoothing.

No Pareto/minimum-layer contribution.

Metric class:

```text
Canonical
Project-specific region aggregation
```

Interpretation:

> mean Stage 10A evidence quality of all selected-length candidate windows fully contained in the requested longer region.

Not an efficacy probability.

## `stage11_region_start_feature`

Transcript feature containing `stage11_region_start_1based`.

Current values:

```text
5UTR
CDS
3UTR
```

Canonical rule:

> assignment depends only on the region starting nucleotide.

A region may extend into the next transcript feature without changing this field.

## `stage11_region_sequence`

Exact transcript subsequence:

```text
transcript[
    stage11_region_start_1based :
    stage11_region_end_1based
]
```

using 1-based inclusive biological coordinates.

Presentation field; not a score.

## `stage11_valid_region_count`

For valid:

```text
R >= L
R <= T
```

where `T` is transcript length:

```text
T - R + 1
```

Otherwise:

```text
0
```

## `stage11_top5_region`

Presentation selection within one:

```text
stage11_region_start_feature
```

for the current:

```text
guide length
region length
metric mode
```

The five regions with highest `stage11_region_mean_score`.

Overlapping regions are allowed.

If fewer than five valid regions exist, return all available rows and represent unavailable rows as `N/A`.

## `stage11_bottom5_region`

Equivalent selection of the five lowest-scoring regions.

Overlapping regions are allowed.

## `stage11_display_tie_order`

When two region scores are numerically identical, lower start coordinate is used only to make top/bottom table display order deterministic.

This is not a scientific ranking metric and does not alter the tied scores.

# 35. Rule for introducing a new metric

Every future metric must document:

1. name;
2. mathematical definition;
3. metric class;
4. input data;
5. analysis unit;
6. deduplication/weighting rule;
7. normalization;
8. biological question;
9. interpretation of high/low values;
10. zero/undefined handling;
11. uncertainty method;
12. limitations;
13. relationship to existing metrics;
14. whether definition was fixed before inspecting the result;
15. candidate-length support / validation status.

No important statistic should exist only inside code.
